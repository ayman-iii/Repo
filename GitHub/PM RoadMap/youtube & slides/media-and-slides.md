## How to add the actual media files

For a true offline GitHub archive, export each Canva presentation from the owner's Canva account as PDF or PNG, download permitted public videos or add official YouTube URLs, then place them under `media/slides/` and `media/video-links.md`. The current package intentionally contains links and metadata only because the supplied Canva pages did not expose downloadable assets through the available public fetch, and the YouTube Studio page required login.
