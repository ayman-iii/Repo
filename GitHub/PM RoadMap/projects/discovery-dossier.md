# Discovery dossier

**Goal:** Choose one real problem and move from request to need.

## Deliverables

- [ ] Problem statement
- [ ] 5 Whys / root-need analysis
- [ ] B2B role map if relevant
- [ ] Assumptions and evidence table
- [ ] Decision log

## Acceptance criteria

- Decisions are explicit and traceable to evidence or labeled assumptions.
- Outcomes are defined before features.
- Risks, stakeholders, and unknowns are visible.
- The artifact is understandable without a live presentation.
